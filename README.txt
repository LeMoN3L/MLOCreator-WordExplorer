MLO Creator by LeMoNeL
V1.5.3 - Community Beta

A modified build of MLO Creator, originally created by Tempus.

START
1. Keep this folder together and run MloCreator V1.5.3.exe.
2. Use your own GTA V Legacy installation for game-file lookup and World Explorer.
3. Set your GTA V folder in settings.json if it is not detected automatically.
4. My Projects opens the interior editor. World Explorer opens the map workspace.

GTA V FOLDER
Close the app and open settings.json beside the executable with a text editor.
An empty gtaPath lets the app try automatic detection. To set it manually, use:
{"gtaPath":"D:/Games/Grand Theft Auto V Legacy"}
Replace the example with your game folder containing GTA5.exe, not the FiveM folder.
Use forward slashes (/) in the JSON path, save the file and restart the application.
Keep the filename settings.json, not settings.json.txt.

REQUIREMENTS
Windows 10/11, 64-bit, .NET Framework 4.8, and Microsoft Edge WebView2 Runtime.

FIRST RUN
This package contains no saved projects, personal settings or prepared world cache.
The application creates working folders as needed. Initial world preparation can
take longer; model and texture caches are generated on your own computer.
Your existing Windows-user cache/settings, if any, can still be reused by the app.

where relevant, and a screenshot or recording when reporting a problem.
