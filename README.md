This is my modified community build of MLO Creator, originally created by Tempus. The main addition is World Explorer, alongside improvements to the interior editor, interface and export workflow.

What is World Explorer?
World Explorer lets you browse the GTA V map directly inside MLO Creator using your own GTA V installation.
You can select a building and use Go to project to start an interior project from that selection, keeping the map browsing and interior editing workflow in the same application.

Main additions and changes:
• HD/LOD map streaming and cached assets.
• Create maps, browse props, move/rotate models and edit flags.
• Delete props and map lights, edit collisions and export for FiveM.
• Selective model, texture and YMAP XML export.
• Weather presets, lighting and shadows.
• Auto room detection, automatic window cutting and glass transparency.
• Updated interface, camera controls and animations.

Interior editor improvements
○ Auto detect room to speed up the initial interior setup.
○Auto Cut Windows, with replacement windows snapping and fitting to detected openings.
○Delete blue faces to select a local window group instead of removing every face individually.
○Glass Transparency controls with viewport feedback.
○ Persistent game-texture caching and improvements to texture loading.
○ Camera navigation closer to Blender, including viewing objects from below.
○ Controls for hiding helper lines.
○ Resizable panels, larger prop previews and a charcoal/orange interface.
○ Animated introduction, loading indicators and smoother screen transitions.

Still in beta: some bugs remain. Feedback and bug reports are welcome!
