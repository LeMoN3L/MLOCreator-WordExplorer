MLO Creator by LeMoNeL
V1.5.3 - Community Beta
Package prepared: 2026-11-19

INSTALL AND START
1. Extract the entire ZIP into a writable folder on your computer.
2. Keep lib, ui and models beside MloCreator V1.5.3.exe.
3. Run MloCreator V1.5.3.exe from the extracted folder.
Do not run the executable inside the ZIP or copy only the executable.

REQUIREMENTS
Windows 10/11, 64-bit, .NET Framework 4.8 and Microsoft Edge WebView2 Runtime.
Use your own GTA V Legacy installation for World Explorer and game-file lookup.

GTA V FOLDER
If the game is not detected, close the app and edit settings.json beside the EXE.
Replace the empty gtaPath with your GTA V folder, for example:
{"gtaPath":"D:/Games/Grand Theft Auto V Legacy"}
Use forward slashes (/) and choose the folder containing GTA5.exe.
Keep the filename settings.json, not settings.json.txt, then restart the app.

FIRST RUN
This package contains no projects, world edits, logs or generated caches.
World caches and working folders are created locally when needed.
The first world load can take longer while game files are prepared.
My Projects opens the interior editor. World Explorer opens the map workspace.
Previously installed user-profile browser data can still exist on your computer.

BETA
Some bugs and unsupported cases remain. Include reproduction steps, a screenshot
and the relevant model/resource name when reporting a problem.
Play Test is an editor preview and does not reproduce the complete GTA V engine.
